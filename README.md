🍅 Pomodoro Timer
A sleek, responsive time management application built on the Pomodoro Technique. This project is designed to help users maximize productivity and maintain focus by breaking work into manageable intervals.

✨ Features
Pomodoro Timer: Standard 25-minute focus sessions.

Break System: Toggle between Short Breaks (5 min) and Long Breaks (15 min).

Customization: Adjustable session lengths to fit your personal workflow.

Audio Alerts: Clear notifications when a session or break ends.

Responsive UI: Optimized for both desktop and mobile devices.

Getting Started:
Follow these steps to run the project locally:

Clone the repository:

```
git clone https://github.com/Darmsztradt/PomodoroTimer.git
```
Navigate to the project directory:
```
cd PomodoroTimer
```
Install dependencies:
```
npm install
```
Run the development server:
```
npm run dev
```
Open http://localhost:3000 in your browser to see the result.
